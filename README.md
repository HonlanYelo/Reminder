# Reminder · 小提醒

Windows 桌面待办 + 定时提醒。界面按 `reminder_preview.html` 的浅蓝玻璃风重做，
技术栈 **PySide6 + SQLite + Python 标准库**，图标全部是运行时渲染的线性 SVG，界面内没有 emoji。

## 运行

**双击 `main.py`，或在任意终端 `python main.py`**，都能直接打开。

`main.py` 开头有自引导：如果当前解释器没装 PySide6，会自动改用同目录下的
`.venv\Scripts\pythonw.exe` 重新拉起自己（`--selftest` 等参数会一并传过去），
所以既不用激活环境，也不会往系统 Python 里装东西。

项目自带 `.venv`（Python 3.13 + PySide6 6.12），不随 git 提交。换机器或删了重建：

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -i https://pypi.org/simple PySide6
```

`python main.py --selftest` 会在 1.5 秒后自动退出，用来确认环境能正常启动。

## 启动过渡

进程第一次绘制文字要初始化字体引擎，在本机约 1 秒，这段时间窗口是空白的。
现在的处理是把它拆成三段，保证任何时刻屏幕上都有东西：

1. `splash.py` 先画出卡片骨架（图标 + 两条占位条 + 进度条），只画图形，几十毫秒上屏
2. `MainWindow` 构建过程中通过 `on_stage` 回调汇报进度，进度条按阶段前进（样式表也延后到卡片出现之后再套）
3. 主窗口用 260ms 淡入，启动卡片同时淡出

`splash.py` 里刻意没有做透明度淡入：紧接着的字体初始化会占满主线程，动画一帧都推不动，
窗口会卡在全透明状态。同理 `main.py` 里给 `windowOpacity` 留了 3 秒兜底，避免异常情况下窗口永久隐身。

## 功能

**任务**
- 新建 / 编辑走弹窗：点「新建任务」或点任意卡片，弹出遮罩 + 居中表单，Esc 或点外部即关闭
- 表单项：内容、提醒时间（点开只选时/分，日期沿用原值、新建即当天）、重复（不重复 / 每天 / 每周 / 每月 / 工作日）、备注
- 右侧「完成」胶囊按钮切换状态，完成后原地变「已完成」并保留在列表里，再点一次即撤销
- 重复任务完成后自动滚动到下一次，不会堆积历史条目
- 左侧筛选：全部 / 今天 / 即将提醒 / 已完成，带实时计数；顶部支持搜索
- 每张未完成卡片显示「还剩多久」（如 还有 3 小时 20 分 / 已逾期 5 分钟），10 秒自动刷新，
  剩 10 分钟内转橙、已逾期转红，完成后隐藏

**提醒**
- 后台线程每 2 秒巡检一次，到点只发一条系统托盘通知（Windows 原生横幅），界面上不叠加任何浮窗
- 提示音由系统通知自己播放，程序不再额外 beep，不会响两次
- 极端情况（系统托盘不可用）：直接把窗口提到前面，并按设置补一声提示音
- 关窗口不退出：静默隐藏到托盘继续计时，双击托盘图标或在菜单里唤回
- 启动时把 12 小时以前就该响的旧任务静默掉，避免一次弹一堆

**其他**
- 单实例：重复启动只会唤起已有窗口
- 设置页：关闭到托盘、无托盘时提示音、打开数据目录、清理已完成
- 数据库开了 WAL，界面写、后台线程读互不阻塞

## 数据

| 位置 | 内容 |
| --- | --- |
| `%APPDATA%\ReminderDesk\reminder.db` | 任务、重复规则、设置（SQLite） |
| `%APPDATA%\ReminderDesk\tasks.json` | 旧版数据，首次启动会自动导入后不再使用 |

表结构：

```sql
tasks(id, title, note, due, repeat, done, done_at, notified, created_at)
meta(key, value)
```

## 文件

| 文件 | 作用 |
| --- | --- |
| `main.py` | 入口：环境自引导、应用初始化、启动过渡编排、托盘菜单、单实例 |
| `mainwindow.py` | 主窗口：侧边导航、任务列表、设置页 |
| `splash.py` | 启动过渡卡片：骨架帧、阶段进度、淡出 |
| `taskdialog.py` | 新建/编辑任务弹窗：遮罩层、表单、提交收起 |
| `datefield.py` | 时间选择：显示框 + 时/分浮层（只选时间） |
| `widgets.py` | 自绘控件：导航项、任务卡片、图标按钮、标题栏 |
| `storage.py` | SQLite 存储、重复规则计算、时间格式化 |
| `scheduler.py` | 后台调度线程（QThread + Event 控制暂停） |
| `icons.py` | SVG 图标路径 → 按颜色渲染 QPixmap/QIcon |
| `theme.py` | 配色与全局 QSS |
| `assets/check.svg` | 复选框对勾（QSS 用） |
| `reminder_preview.html` | 界面视觉参考稿（不参与运行） |

## 备注

- 只验证了 Windows（托盘、`%APPDATA%` 路径）。Qt 本身跨平台，换系统需要改数据目录。
- 没有打包 exe，直接跑源码即可；要打包再加 PyInstaller。
- 如果托盘不可用（极端情况），关闭窗口会直接退出程序，不会变成看不见的后台进程。
